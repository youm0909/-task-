# 残り時間タスク (Time-Left Task Manager)

期限が近づくにつれてバーが減っていく直感的タスク管理アプリです。  
**Supabase**（認証・データベース・リアルタイム同期・RLSセキュリティ）と **Vercel**（高速ホスティング）を使用して安全に公開・運用できます。

---

## 主な機能

- ⏱️ **残り時間の視覚化**: 期限の7日前（168時間前）からバーが徐々に減少し、緊急度がひと目でわかります。
- 🔒 **強固なセキュリティ（RLS）**: PostgreSQL の「行レベルセキュリティ（Row Level Security）」により、データベース本体で他人のデータへのアクセスを遮断。
- 👥 **リアルタイム共同タスク**: 
  - タスクごとに「共有コード（6桁）」を発行
  - 仲間がコードを入力すると、同じタスクをリアルタイムに共同編集・完了チェックできます。
  - Supabase Realtime により、誰かが操作すると画面を更新することなく即座に全員の画面に反映されます。
- 📅 **月間カレンダー & 今日のタスク**: 祝日対応のカレンダー表示と、今日やるべきことの集中管理。
- 🔄 **くり返し・サブタスク・カレンダー(.ics)取り込み**: 毎日のルーチンやサブタスクの管理も可能。

## 公開手順（3ステップ）

### ステップ 1: Supabase のセットアップ（約3分）

1. [Supabase (https://supabase.com)](https://supabase.com) にアクセスしてログイン（アカウントがない場合は無料登録）。
2. **「New Project」** をクリックして新しいプロジェクトを作成します（データベースのパスワードを設定し、リージョンは「Tokyo (ap-northeast-1)」等を選択）。
3. プロジェクトが作成されたら、左側メニューの **「SQL Editor」** を開きます。
4. **「New query」** をクリックし、本プロジェクトの **[`schema.sql`](./schema.sql)** の内容をすべてコピーして貼り付け、右下の **「Run」** を実行します。
   - これにより、`tasks` テーブル、`task_members` テーブル、RLS ポリシー、共有コード参加関数（RPC）、Realtime 同期がすべて一発で設定されます。
5. 左側メニュー下の **「Project Settings（歯車アイコン）」** -> **「API」** を開きます。
   - **`Project URL`**
   - **`Project API keys`** の **`anon` (public)**
   の2つの値をメモします。

---

### ステップ 2: 接続設定

接続情報をアプリに反映する方法は 2 通りあります。どちらでも構いません。

#### 方法 A: `config.js` に記述する（おすすめ）
[`config.js`](./config.js) を開き、先ほどコピーした値を貼り付けて保存します。
```javascript
window.SUPABASE_CONFIG = {
  url: "https://xxxxxxxxxxxxxxxx.supabase.co",
  anonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
};
```

#### 方法 B: 画面上から入力する
コードを編集しなくても、ブラウザでアプリを開き、画面右上の **「⚙️ Supabase設定」** をクリックして Project URL と anon key を入力・保存すれば即座に接続されます（ブラウザ内に安全に保存されます）。

---

### ステップ 3: Vercel にデプロイして公開（約2分）

本アプリは静的Webアプリ（SPA）のため、ビルド作業なしでそのまま Vercel で無料公開できます。

#### 手順（GitHub 連携）:
1. このフォルダを GitHub のリポジトリにプッシュします：
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   # GitHub でリポジトリを作成後:
   git remote add origin https://github.com/あなたのユーザー名/リポジトリ名.git
   git branch -M main
   git push -u origin main
   ```
2. [Vercel (https://vercel.com)](https://vercel.com) にログインし、**「Add New...」 -> 「Project」** を選択します。
3. 先ほどプッシュした GitHub リポジトリを選択し、**「Deploy」** をクリックします（ビルド設定はデフォルトのままで自動認識されます）。
4. 数十秒でデプロイが完了し、公開URL（`https://xxx.vercel.app`）が発行されます！

## 使い方ガイド

### 1. アカウント作成・ログイン
- 画面右上の **「ログイン / 新規登録」** ボタンから、メールアドレスとパスワードを入力して登録・ログインします。
- ログインするとクラウド同期モードになり、PC・スマホ問わずタスクがリアルタイムに同期されます。

### 2. 共同タスク機能の使い方
1. **タスクを共有する（作成者）**:
   - 共有したいタスクの **「👥 共有する」** ボタンを押すと、6桁の共有コード（例: `A8K2F9`）が発行されます。
   - 共同作業したい相手にそのコードを伝えます。
2. **共有されたタスクに参加する（仲間・参加者）**:
   - ログイン後、画面右上の **「👥 共同タスクに参加」** をクリックします。
   - 共有コードを入力して「参加する」を押すと、そのタスクが自分のタスク一覧に自動追加されます。
   - 一方がサブタスクにチェックを入れたり完了にすると、もう一方の画面でもリアルタイムに反映されます。
